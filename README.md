# Restaurant Table Reservation System

IFN636 Assessment 1 — Software Life Cycle Management

## Overview
A web application allowing customers to browse and book restaurant tables, and admins to manage tables and reservations.

## Tech Stack
- Backend: Node.js, Express, MongoDB (Mongoose)
- Frontend: React
- Deployment: AWS EC2

## Setup
1. Clone the repository
2. Backend: `cd backend && npm install`
3. Create a `.env` file in `backend/` with `MONGO_URI`, `JWT_SECRET`, `PORT`
4. Run backend: `node server.js`
